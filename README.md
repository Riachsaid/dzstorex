# DZStoreX

متجر DZStoreX: صفحة منتجات، صفحة مستقلة لكل منتج برابط ثابت، نموذج طلب، ومساعد ذكي بالدارجة/العربية/الفرنسية.

- الموقع المنشور: <https://riachsaid.github.io/dzstorex/>
- صفحة منتج مثال: <https://riachsaid.github.io/dzstorex/product.html?id=5291>

## بنية المشروع

```
index.html                 الصفحة الرئيسية: شبكة المنتجات + نموذج الطلب
product.html               صفحة منتج واحدة مشتركة، تُقرأ عبر ?id=PRODUCT_ID
assets/css/store.css       التصميم (RTL عربي، نفس هوية DZStoreX)
assets/js/config.js        عنوان الخادم العام (لا يحتوي أي أسرار)
assets/js/wilayas.js       كل الولايات الـ58
assets/js/api.js           استدعاءات واجهة المنتجات والطلبات
assets/js/chat.js          عميل المساعد الذكي
assets/js/order-form.js    منطق نموذج الطلب المشترك + التحقق
assets/js/home.js          شبكة المنتجات ونموذج الصفحة الرئيسية
assets/js/product.js       قراءة ?id=، العرض، معرض الصور، الطلب
assets/img/placeholder.svg صورة بديلة عند غياب صورة المنتج
assets/products/<id>/      صور المنتجات مستضافة محلياً (لا روابط موردين)
```

## كيف تعمل صفحة المنتج

كل منتج له معرّف رقمي ثابت (`product_id`) لا يتغير أبداً. صفحة واحدة تخدم كل المنتجات:

```
product.html?id=5291
```

الصفحة تجلب بيانات المنتج من الخادم ثم تعرض: الصور، الاسم، الوصف، **السعر النهائي**، حالة التوفر، وزر «اطلب الآن».
إذا كان `id` غير موجود تظهر رسالة «المنتج غير موجود»، وإذا كان غير صالح تظهر رسالة خطأ بدون أي بيانات.

## الخادم (n8n)

الواجهة تتصل بخادم n8n عبر نطاق عام واحد:

| الوظيفة | الطريقة | المسار |
|---|---|---|
| المنتجات | `GET` | `/webhook/dzstorex/products` و `?id=PRODUCT_ID` |
| الطلبات | `POST` | `/webhook/dzstorex/orders` |
| المساعد الذكي | `POST` | `/webhook/dzstorex/chat` |

قاعدة البيانات (كتالوج المنتجات والطلبات) تعيش داخل n8n، وليست في هذا المستودع.

### نموذج الطلب

الحقول: الاسم الكامل، رقم الهاتف الجزائري، الولاية (58)، البلدية، العنوان التفصيلي، المنتج، الكمية (1–10)، شركة التوصيل (Yalidine أو ZR Express)، ملاحظات.

- التحقق يتم في المتصفح **وفي الخادم**.
- الخادم يعيد حساب السعر بنفسه؛ أي سعر يرسله المتصفح يُتجاهل.
- الطلب يُسجّل بحالة `received` فقط. الاستجابة تقول «تم استلام طلبك» وليس «تم تأكيد الطلب».
- التأكيد يتم هاتفياً من الفريق.

## قواعد الأمان والخصوصية

- لا توجد أي بيانات مورد (اسم، رابط، معرّف منتج، سعر أصلي، هامش) في HTML أو JS أو استجابات الواجهة.
- السعر النهائي يُحسب على الخادم: `السعر الأصلي + هامش ثابت`. المتصفح يستقبل الرقم النهائي فقط.
- الصور مستضافة داخل هذا المستودع، وليست روابط من مواقع الموردين.
- مفاتيح الخدمات لا توجد في الواجهة؛ الاتصال بالخادم العام فقط.
- CORS مقيّد بنطاق الموقع المنشور.
- المنتج بدون تحقق موثّق من التوفر يظهر كـ «التوفر غير مؤكد» ولا يمكن طلبه.

## المساعد الذكي

- يعمل على Qwen 3 8B محلياً عبر Ollama داخل n8n.
- يظهر كزر دائري عائم أسفل يمين الصفحة، ويفتح لوحة محادثة مصغّرة فوق أي صفحة.
- يستقبل سياق المنتج الحالي من الخادم، ويتذكر المحادثة عبر معرّف جلسة في `sessionStorage`؛ يبقى سجل المحادثة أثناء التنقل داخل الموقع وطالما الصفحة مفتوحة.
- لا يخترع السعر أو المخزون أو المواصفات أو مصاريف التوصيل.
- يرفض الكشف عن معلومات المورد.
- لا يقول إن الطلب وصل إلا إذا كان هناك طلب فعلي في السياق، ويذكر رقمه.

## تشغيل محلي

الموقع ملفات ثابتة:

```bash
python -m http.server 8000
```

ثم افتح <http://localhost:8000/>. ملاحظة: الخادم يسمح فقط بنطاق GitHub Pages، لذلك استدعاءات الواجهة من `localhost` ستحتاج وسيطاً محلياً أو اختباراً على الموقع المنشور.

## تحديث الكتالوج

لإضافة أو تعديل منتج: حدّث صفّه في كتالوج n8n (الاسم، الوصف، الصور، السعر الأصلي، حالة التوفر وتاريخ التحقق)، وارفع صوره تحت `assets/products/<id>/`.
لا حاجة لتعديل أي صفحة HTML: `product.html?id=<id>` سيعرض المنتج مباشرة، والرابط يبقى ثابتاً.
